# ASTRAL BASTION: LEYLINE ESCORT / 星界堡壘：靈脈護送

Play: https://windfaller.github.io/astral-bastion/

Independent prototype. Dev server port 8788.

## Full run
1. New Run, pick 3-4 Valkyries (Rin, Alyssa, Eve start unlocked).
2. Nodes from src/game/data/stages.ts: tutorial, twin feeders, 3-pick, event, elite, rest, YAMATO-0, victory.
3. Drag deploy, click accel node, ult/link/Aria mark.
4. Win if Core integrity >= 1 at the gate. Rewards change the next fight.
5. First clear saves unlocks to astral-bastion-save-v1.

## Scripts
Use package.json scripts: dev, build, preview, check.

Skip and Fast only change animation. Combat is simulated first.
